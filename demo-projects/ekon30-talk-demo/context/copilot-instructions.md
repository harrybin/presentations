# Projektregeln · Demo-Vorlage

- Delphi-kompatibles Object Pascal im FPC-Delphi-Modus verwenden.
- Tracks exakt und case-sensitiv vergleichen; Reihenfolge des ersten Auftretens erhalten.
- Eingaben nicht verändern; bei fachlichen Änderungen die bestehenden Checks ausführen.
- Tests oder Erwartungen nicht abschwächen, um einen grünen Lauf zu erhalten.
