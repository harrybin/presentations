# 5. Hooks und React Context

**Ziel:** State passend platzieren und notwendige Werte über Context bereitstellen.

1. Such- und Trackfilter mit `useState` ergänzen.
2. Die Session-Liste aus den Daten und Filtern ableiten, statt Ergebnis-State zu duplizieren.
3. Merkliste in einen Context mit typisiertem Hook auslagern.
4. Context nur verwenden, wenn Werte über mehrere Komponenten gebraucht werden.
5. Einen `useEffect` nur dort ergänzen, wo eine Synchronisation mit einem externen System nötig ist.

**Checkpoint:** Ordne jeden State als lokal, abgeleitet oder gemeinsam genutzt ein.
