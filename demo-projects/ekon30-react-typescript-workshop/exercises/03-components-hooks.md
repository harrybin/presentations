# 3. Funktionale Komponenten und Hooks

**Ziel:** Daten über Props darstellen und lokales Verhalten mit Hooks ergänzen.

1. Die Session-Darstellung in eine `SessionCard`-Komponente auslagern.
2. Props über `Session` typisieren.
3. Eine lokale Auswahl mit `useState` umsetzen.
4. React Developer Tools oder Browser-Debugger verwenden, um Rendern und Ereignisse nachzuvollziehen.
5. Lifecycle Methods als Klassenmodell mit `useEffect`-Synchronisation vergleichen.

**Checkpoint:** Beschreibe, was ein Event auslöst und wie React anschließend die UI aus dem State berechnet.
