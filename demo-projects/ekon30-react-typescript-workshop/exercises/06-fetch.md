# 6. REST-Daten und Fetch API

**Ziel:** Session-Daten abrufen und Netzwerkzustände in der UI darstellen.

1. Die Beispieldaten in `public/sessions.json` ansehen.
2. Einen typisierten Fetch-Aufruf für `/sessions.json` ergänzen.
3. Loading-, Erfolgs-, Fehler- und leere Zustände abbilden.
4. `Response.ok` prüfen; `fetch` verwirft nicht automatisch bei HTTP 4xx/5xx.
5. Request, Status und Antwort im Browser-Debugger prüfen.

**Checkpoint:** Erkläre, welche Laufzeitprüfung erforderlich ist, bevor externe JSON-Daten als `Session[]` behandelt werden.
