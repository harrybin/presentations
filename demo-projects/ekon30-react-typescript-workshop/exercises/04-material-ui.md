# 4. Material UI: Komponenten, Layout und Styling

**Ziel:** eine konsistente und responsive Oberfläche mit möglichst wenig eigenem CSS bauen.

1. Die vorhandene MUI AppBar und Cards nachvollziehen.
2. Mit `Stack`, `Grid` oder `Box` den Seitenaufbau ergänzen.
3. Theme-Farbe und Typografie zentral anpassen.
4. Layout im schmalen und breiten Viewport prüfen.
5. Ein Beispiel für einen CSS-/Layout-Fallstrick beim Desktop-Web-Wechsel notieren.

**Checkpoint:** Die App bleibt auf einem schmalen Viewport lesbar und bedienbar.
