# Workshop-Übungen

Arbeite in Reihenfolge am Session-Katalog. Jede Übung hat ein Ziel und einen Checkpoint. Nach einem Schritt die App im Browser prüfen und TypeScript/Browser-Konsole beobachten.

## Ablauf

1. `01-tooling.md` - Node.js, npm, Vite, VS Code und Browser-Debugging
2. `02-typescript.md` - Types, Interfaces, Generics und Datenverträge
3. `03-components-hooks.md` - Props, Events, funktionale Komponenten und Hooks
4. `04-material-ui.md` - MUI-Komponenten, Theme, Layout und responsive Ansichten
5. `05-context.md` - State, Hooks und React Context
6. `06-fetch.md` - REST-Daten, Fetch API und Fehlerzustände
7. `optional.md` - AutoRest, Playwright, App-Konfiguration und weitere Vertiefungen

Die Dateien im Starter sind bewusst klein. Entwickle die App in kleinen, nachvollziehbaren Schritten und erkläre, wo der State lebt und wie Daten fließen.
