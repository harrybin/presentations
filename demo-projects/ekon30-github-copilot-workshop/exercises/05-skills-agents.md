# 5. Skills und Custom Agents

**Ziel:** eine wiederkehrende Aufgabe als Workflow beschreiben und von einer Rolle unterscheiden.

1. Beschreibe im Skill `catalog-test-review` den Ablauf: Kriterien lesen, Tests ergänzen, Tests ausführen, Diff prüfen.
2. Lege passende Ressourcen nur in den Skill-Ordner, wenn sie für diesen Ablauf gebraucht werden.
3. Entwirf optional einen read-only Reviewer-Agenten, der Findings meldet und keine Dateien ändert.
4. Notiere, wann der Skill passt und wann er nicht geladen werden sollte.

**Checkpoint:** Ein Skill bündelt Workflow-Wissen; ein Custom Agent definiert eine spezialisierte Rolle mit passenden Grenzen.
