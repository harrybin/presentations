# 1. Completions

**Ziel:** Vorschläge im eigenen Schreibrhythmus bewerten und mit Tests absichern.

1. `src/catalog.js` und die bestehenden Tests lesen.
2. In einer neuen Funktion eine Beschreibung für `countSessionsByTrack` beginnen und Copilot vervollständigen lassen.
3. Mindestens einen Vorschlag akzeptieren und einen anderen bewusst ändern oder verwerfen.
4. Die Acceptance Criteria in `backlog/feature-request.md` in Tests übersetzen.
5. `npm test` ausführen und den Diff reviewen.

**Checkpoint:** Erkläre, welches wichtige Detail der Vorschlag nicht aus dem aktuellen Dateikontext wissen konnte.
