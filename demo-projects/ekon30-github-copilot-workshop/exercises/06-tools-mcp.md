# 6. Tools und MCP (optional)

**Ziel:** externe Fähigkeiten mit minimal nötigen Rechten bewerten.

1. Beschreibe, welche externe Information oder Aktion im Katalog-Workflow fehlen könnte.
2. Prüfe bei einem bereitgestellten MCP-Beispiel Serverherkunft, Tools, Eingaben und Berechtigungen.
3. Bevorzuge zum Erkunden einen lesenden Zugriff und verwende ausschließlich Beispieldaten.
4. Führe keine produktiven Schreibaktionen und keine nicht geprüften Befehle aus.

**Checkpoint:** Erkläre, welche Daten den Prozess verlassen und welche Bestätigung eine Aktion benötigt.
