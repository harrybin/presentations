# 7. Capstone: euer Copilot-Workflow

**Ziel:** eine vollständige, nachvollziehbare Schleife mit Copilot durchführen.

1. Wähle eine kleine Änderung im Session-Katalog.
2. Nutze Instructions für Projektregeln und Prompt oder Skill für den passenden Task.
3. Lass den Agenten zuerst Scope und Verifikation benennen.
4. Prüfe Tests, Diff und Annahmen selbst.
5. Notiere, was du für ein echtes Projekt ergänzen oder anders begrenzen würdest.
