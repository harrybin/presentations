# 3. Agent Mode: Feature im begrenzten Scope

**Ziel:** eine mehrstufige Aufgabe erst planen, dann gezielt umsetzen lassen.

1. `backlog/feature-request.md` lesen und offene Fragen notieren.
2. Copilot Agent Mode ausschließlich einen Plan für die Acceptance Criteria erstellen lassen.
3. Den Plan mit den Akzeptanzkriterien vergleichen und Scope klären.
4. Umsetzung freigeben; Änderungen und Tests beobachten.
5. `npm test`, `git diff` und die Input-Immutability prüfen.

**Checkpoint:** Zeige mindestens eine Annahme oder Grenze, die du selbst überprüft hast.
