# 2. Chat: erst verstehen, dann ändern

**Ziel:** Projektkontext gezielt in eine Frage und einen kleinen Auftrag übersetzen.

1. Copilot Chat bitten, `src/catalog.js` und `tests/catalog.test.js` zu erklären.
2. Nach Randfällen von `filterSessions` fragen, ohne Dateien zu ändern.
3. Einen Testfall aus der Antwort auswählen und selbst auf Richtigkeit prüfen.
4. Copilot um einen kleinen, testbaren Vorschlag bitten.
5. Tests und Änderungs-Diff prüfen.

**Checkpoint:** Unterscheide bestätigte Fakten, Annahmen und noch offene Anforderungen.
