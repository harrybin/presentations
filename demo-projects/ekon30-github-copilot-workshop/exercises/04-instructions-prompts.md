# 4. Instructions und Prompt Files

**Ziel:** dauerhafte Projektregeln von einem gezielt gestarteten Auftrag trennen.

1. Erstelle `.github/copilot-instructions.md` mit drei konkreten, überprüfbaren Regeln.
2. Lass Copilot eine kleine Änderung unter diesen Regeln vorschlagen.
3. Erstelle `.github/prompts/test-review.prompt.md` als wiederverwendbare Test-Review-Vorlage.
4. Vergleiche, welche Information automatisch gilt und welche du bewusst aufrufst.

**Checkpoint:** Regeln beschreiben gewünschtes Verhalten, nicht vage Eigenschaften wie „sauberer Code“.
